# Activation & Onboarding Funnel Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on analysing the user activation and onboarding funnel to identify where users drop off, quantify the impact of each funnel stage, and understand activation performance across different user segments.

The analysis helps identify important areas for improvement and provides data-driven hypotheses that can be considered for future experiments.

## Project Objectives

* Analyse the complete activation and onboarding funnel.
* Identify major user drop-off points.
* Measure activation rate across different segments.
* Analyse activation by device, acquisition source, and marketplace side.
* Analyse revenue patterns across acquisition sources.
* Identify opportunities for improving user activation.

## Data Preparation

The raw dataset was cleaned and prepared using *Microsoft Excel*.

The cleaning process included:

* Removing duplicate records.
* Standardizing column names and text values.
* Handling missing values.
* Converting fields into appropriate data types.
* Checking funnel-stage values.
* Validating revenue values.
* Performing basic data quality checks.

The cleaned dataset was then used for further analysis.

## Data Analysis

Python was used for exploratory and business analysis after the data-cleaning stage.

The analysis covered:

* Total users and activated users.
* Overall activation rate.
* Funnel-stage conversion and drop-off.
* Activation by marketplace side.
* Activation by device.
* Activation by acquisition source.
* Revenue analysis.
* Identification of major drop-off stages.
* Revenue opportunity analysis.

## Tableau Dashboard

A Tableau dashboard was created to provide an interactive view of the activation funnel.

The dashboard includes:

* KPI overview.
* Activation funnel.
* Stage-wise drop-off analysis.
* Activation by device.
* Activation by acquisition source.
* Marketplace-side activation.
* Revenue by acquisition source.
* Interactive filters for user segmentation.

## Business Outcome

The project provides a structured view of the activation journey and highlights the stages where user loss can be investigated further. The findings can be used to develop and prioritize hypotheses for future experiments.

## Conclusion

This project demonstrates an end-to-end data analytics workflow, from Excel-based data preparation to Python analysis and Tableau visualization. It focuses on converting funnel data into actionable insights for improving user activation and onboarding performance.
